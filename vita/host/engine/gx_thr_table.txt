# gx_thr_table.txt -- THE THREADED DISPOSITION of every GX boundary symbol (RT_THREAD.md section 4).  INPUT of host/engine/gen_gx_rec.py (module gen); written by the planner, not by a module.
# thr:  S = state setter (R2, R2_STATE.md): while R2 is active G runs gxh_g_X (the HAL body on G's instance) and marks dirty groups; the legacy path (R2 off) records by value like R
#       R = record by value on G, replay __real_X on R (generated both sides)      L = run __real_X on G, nothing recorded (G-M1 proves the body touches no R-owned static)
#       X = custom: G side gxts_G_X(params), R side gxts_R_X(payload) -- both in src/gx_rt_special.c      P = pipe byte (gx_rt.h inline writers)
#       E = "R-drop": on R the wrapper returns at once (the replayed real body reaches it across objects), on G it runs the real function      T = viewer-only trap: counts, then real
# edge: 1 = a HAL object itself references this symbol across objects, so on R the wrapper must call __real_X (generated: if (gxt_on_R()) return __real_X(...))
# FORMAT  name|thr|edge|why         (one row per row of gen_gx_rec.py TABLE_TEXT + the 7 pipe rows, then [extra] rows with the full prototype)
